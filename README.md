# NovelCrawl

基于 Playwright + BeautifulSoup 的异步小说爬虫，仅供个人学习和研究使用。

1. **尊重版权** — 仅爬取已获得合法授权或处于公共领域的作品。不得将爬取内容用于二次分发、传播或商业行为。

3. **合理请求频率** — 本项目已内置批次间等待机制（默认每 3 章间隔 10 秒），不得修改参数进行高频请求。

### 技术防护措施

本项目已内置以下防护避免滥用：

- **并发限制** — 每批最多 3 章并发请求，可配置但不应大幅提高
- **请求间隔** — 批次间自动等待 10 秒
- **自动重试** — 失败后重试 5 次，避免因临时网络问题造成无效重试
- **无断点续传** — 不支持断点续传，增加批量自动化抓取的成本

如果发现目标服务器返回错误或拒绝访问，请立即停止爬取，不要尝试绕过反爬措施。
